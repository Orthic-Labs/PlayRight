# PlayRight

One low-resource desktop player for the things you already pay for and the things you already have: subscription video services in isolated, persistent sign-in windows; Stremio addons, debrid and torrents through a native player; local files; and, later, music.

**Status:** design stage. No code yet. Nothing here has been tested against a real service; the first milestone is the qualification spike that decides which services work.

- [ARCHITECTURE.md](ARCHITECTURE.md): the design.
- [docs/service-matrix.csv](docs/service-matrix.csv): per-service, per-OS route and qualification status.
